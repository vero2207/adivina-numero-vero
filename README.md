# Adivina el número

## Descripción
Es un juego en Python donde el jugador debe adivinar un número secreto generado aleatoriamente. Se puede elegir entre tres dificultades: fácil, medio y difícil. El programa indica si el número ingresado es mayor o menor que el número secreto y calcula una puntuación al terminar.

## Cómo ejecutarlo
1. Tener instalado Python 3.8 o superior.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el comando `python adivina_numero.py`.
